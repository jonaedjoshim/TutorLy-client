# Tutorly Client

Frontend for Tutorly — a tuition marketplace connecting students and tutors.

## Stack

React 18, Vite, Tailwind CSS, React Router, Axios.

## Getting started

```bash
npm install
cp .env.example .env
npm run dev
```

The dev server runs on `http://localhost:5173` and proxies `/api` to `http://localhost:5000`.

## Design direction

Warm paper background, deep teal primary, terracotta accent, editorial serif headings.
No purple tones.
